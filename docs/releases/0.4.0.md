# 0.4.0 — first open-source release

The existing local inspector is now available under Apache-2.0, with its own
source repository, CLI, TypeScript SDK, offline HTML reader and synthetic tests.
Previous 0.3.1 binaries retain their original files and licence.

This release does not add economic calculations, protocols or financial
guarantees. The CLI arguments and `solana-inspection-v2` contract are unchanged.
Manifests remain version-bound: use the original release to replay an older one.

## Start with a question

- Who actually paid a sponsored transaction's network fee?
- Why can a swap receive 2.5 tokens while the account increases by only 2?
- What does an unexplained balance difference establish — and what does it not?

The [synthetic examples](../../examples/README.md) and
[small SDK assertion](../../recipes/assert-sponsored-fee.mjs) make these questions
reproducible. They do not demonstrate general superiority over other parsers.

## Executed checks and limits

Windows x64 and Ubuntu 24.04 x64 passed on Node 22.12.0, 22.23.2, 24.0.0 and
24.21.0. Linux reproduced the exact archive above. A separate private regression
over 472 archived observations retained byte-identical results from 0.3.1.
See [the detailed verification](../release-verification.md), including the public
CI run, synthetic tests and limits of those claims.

This is an early developer tool. Independent usefulness, repeated adoption,
time savings and commercial demand have not been validated. No accounts, paid
services, wallet connection, telemetry or automatic data collection are needed
to inspect a supplied file.
